# 上架清单：类目资质与提审检查

> 代码侧能准备的都已在项目内完成（隐私政策页、客服入口）。
> 剩下带 ⚠️ 的必须在微信公众平台网页端由你本人操作，我无法代劳。

---

## 一、类目与资质 ⚠️

路径：微信公众平台 → 小程序 → **设置 → 基本设置 → 服务类目**

| 候选类目 | 适用情况 | 资质要求 |
|---|---|---|
| **工具 → 效率**（推荐先试） | 纯工具属性，无需资质 | 个人主体一般可直接选，最省事 |
| **教育 → 在线教育** | 想强调备考属性 | 个人主体**可能需要**《办学许可证》或相关资质，地区要求不一 |
| **教育 → 教育信息服务** | 仅提供信息查询 | 多数情况个人主体可选 |

**建议**：先选「工具 → 效率」提交。审核若以「实际功能与类目不符」退回，再按退回提示补充教育类资质或换类目。
最终以公众平台当前可选列表与审核意见为准，我给的是经验判断，不是官方口径。

---

## 二、用户隐私保护指引 ⚠️

路径：**设置 → 服务内容声明 → 用户隐私保护指引 → 更新**

即使不采集任何信息，也必须提交一份声明，否则提审会被卡。按我们代码的实际情况填写：

- **收集的用户信息**：无（不收集）
- **申请的系统权限**：无
- **第三方信息共享**：无
- **数据存储**：仅本地

指引生效后，小程序内会展示「用户隐私保护指引」入口，与我们自带的隐私政策页并存，属正常现象。

---

## 三、客服功能 ⚠️

路径：**功能 → 客服 → 启用**

启用后：
1. 添加客服人员（可用自己的微信号绑定）
2. 建议设置一条自动回复，说明回复时间

代码侧已完成：`我的 → 联系客服` 用的是微信原生客服会话（`open-type="contact"`），
未启用客服功能时按钮点了没反应，属正常，启用后即可用。

---

## 四、提审前自检（代码侧已就绪）

| 检查项 | 状态 |
|---|---|
| 无网络请求、无服务器域名 | ✅ 项目内零 `wx.request` |
| 无未声明的系统权限 | ✅ 未申请任何权限 |
| 隐私政策可在小程序内查看 | ✅ `我的 → 隐私政策` |
| 客服入口 | ✅ `我的 → 联系客服` |
| 无诱导分享 / 无外链 / 无支付 | ✅ |
| 主包体积 < 2MB | ✅ 约 1.2MB，用开发者工具「上传」时复核 |
| 内容与类目一致 | ⚠️ 你自己确认：简介、关键词不要超出实际功能 |

---

## 五、提审材料建议

- **小程序名称**：贝贝四六级（若被占用，可加后缀，如「贝贝四六级单词」）
- **简介**：一行说清是什么，避免「最全」「第一」等极限词
- **关键词**：四六级、CET、英语单词、背单词、六级词汇
- **头像**：用「贝贝」小熊那张（1024×1024）
- **功能页面路径**：首页 `/pages/index/index`

---

## 六、上传与提交

1. 开发者工具右上角 **上传** → 版本号填 `1.0.0`，备注写清这版内容
2. 公众平台 → **管理 → 版本管理** → 开发版本 → **提交审核**
3. 审核通过 → 点 **发布**

> 提示：个人主体小程序审核通常 1–3 个工作日。首次被退回很常见，按退回原因改即可。
