# v0.1.0 发布说明

## 简介

贝贝四六级 v0.1.0 —— 完全离线的英语四六级背单词微信小程序。

内置四级 4,543 词、六级 3,991 词（含音标与例句），基于简化艾宾浩斯记忆曲线安排复习计划，
学习进度、错词本与打卡记录全部保存在本机，无需注册、无需联网、无任何第三方依赖。

## 功能

- **卡片背单词**：正面单词 + 音标，点卡片显示中文释义与例句；认识 / 模糊 / 不认识 三档评价
- **记忆调度**：简化艾宾浩斯间隔重复（stage 0–6，间隔 1/2/4/7/15/30 天），答错的词 10 分钟后即到期
- **撤销**：标错了点「↩」回退，记忆状态、当日统计与历史明细一并还原
- **每日背单词历史**：按日期倒序，每天可展开查看全部单词与释义，支持分页加载
- **查词**：英文前缀 / 英文包含 / 中文释义三段匹配，附音标与例句
- **学习统计**：今日数据、7 / 30 / 90 天学习趋势（坐标轴按区间抽稀）、记忆留存曲线（实测 vs 理论遗忘对照，节点可点开当天单词）
- **每日打卡**：完成学习自动打卡，连续天数与断签处理；首页状态灯实时反馈
- **错词本**：自动收集答错词，专项复习，可标记已掌握
- **设置**：四级 / 六级词库切换、每日目标 10–50 词、加练档位 10/15/20、清空数据
- **合规**：隐私政策页、客服入口、零网络请求、零系统权限

## 技术要点

- 原生小程序（WXML / WXSS / JS），零 npm 依赖、零构建步骤，clone 后用微信开发者工具打开即可运行
- 本地持久化：单根存储对象 + 存储损坏容错回退 + 当日学习队列落盘（中断重进顺序不变）
- 主包 1.28MB / 2MB 上限，冷启动零网络请求
- 视觉：浅色半透明玻璃风格 + 深色模式预留，交互动效全部手写 CSS
- 70 项 Node 冒烟测试：覆盖学习流程、打卡规则、杀进程恢复、跨天队列、存储损坏容错、历史与撤销

## 已知限制

- 暂无发音音频（离线优先的取舍，后续评估在线合成）
- 数据仅存本机，暂无导出 / 备份功能
- 真机预览与上架需替换为自有 AppID（项目内置测试号配置）

## 运行方式

```bash
git clone https://github.com/qqqzj69/cet-word-miniprogram.git
```

用微信开发者工具导入项目根目录（AppID 可选测试号），编译即可运行。
